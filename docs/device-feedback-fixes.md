# Device feedback fixes

Follow-up to app `1d42223` and zig-tachi `c0c6336`, both developed on
`native-downloads` and since merged into `main`. zig-layout and
zig-fabrum-platform-inkview were not modified.

## Extension-compatible zstd

Superseded: the Aircompressor decoder below was replaced by libzstd 1.5.7 over
JNI, built from source by zig-tachi's `zig build`; see [native downloads](native-downloads.md).

The host now supplies `okhttp3.zstd.Zstd` as a Kotlin object implementing
OkHttp 5.5.0's `CompressionInterceptor.DecompressionAlgorithm`. Its encoding is
`zstd`; `decompress(BufferedSource)` returns an Okio Source backed by
`io.airlift.compress.zstd.ZstdInputStream`. Aircompressor 0.27 is Apache-2.0 and
uses Java-8-compatible class files. It needs neither a zstd JNI library nor FFM.
The host still targets Java 17. okhttp-brotli remains: its decoder is the pure
Java `org.brotli.dec.BrotliInputStream`.

Read-only bytecode inspection of the installed jars established that both
MangaFox 1.6.2 and MangaDex 1.6.0 reference just
`okhttp3/zstd/Zstd.INSTANCE:Lokhttp3/zstd/Zstd;` in their shared Keiyoushi code.
The replacement also matches the published artifact's entire public field and
method ABI, including access flags: `INSTANCE`, `getEncoding(): String`, and
`decompress(okio.BufferedSource): okio.Source`. The original artifact contains
no additional zstd extension-function class. The checked extension SHA-256s are:

- MangaFox: `8749c7901a178cbaec179c9ec5310bdfaf870123d61782b93312a99b0d0b5f2f`.
- MangaDex: `2781d8593d68f2e79ad54f20949399c44afb703d5679299f84f7356df697008e`.

`host/tools/check_zstd_abi.py` reproduces the public ABI and extension reference
checks against the official okhttp-zstd 5.5.0 jar. It also rejects bundled
zstd-kmp/zstd-jni implementation classes. No writes were made to the reader.

### Strict-alignment Zero JVM

Stock Aircompressor 0.27 is **not sufficient** on this ARM Zero JVM: the first
ARM fixture faulted with SIGBUS/BUS_ADRALN in `ZstdFrameDecompressor.copyLiterals`
at `Unsafe.getLong(Object,long)` with an unaligned byte-array offset. A scoped
build-time ASM transform rewrites its zstd package's 97 Unsafe word accesses to
`dev.tachi.host.AlignedUnsafe`. Aligned accesses keep the original fast path;
unaligned accesses split into smaller aligned words or byte accesses. This
preserves the little-endian behavior required by upstream. The alignment tool is not invoked at runtime; no agent or native decoder is
needed. Its ASM 9.8 dependency is isolated from runtimeClasspath (dex2jar already
has its own ASM dependencies). Only the transformed dependency jar enters
the host runtime classpath, and the host jar includes the Apache license and a
notice identifying the modification.

The corrected decoder is exercised on the bundled ARMv7 soft-float Java 17 Zero
JVM, rather than relying on desktop behavior. The fixture installs an actual
extension-style `CompressionInterceptor(Zstd.INSTANCE, Brotli.INSTANCE,
Gzip.INSTANCE)`. Its HTTP/TLS server requires zstd in Accept-Encoding, then sends
a real checksummed zstd frame expanding to 69,632 bytes. Browse, details, chapter
list and page-list calls verify the decompressed bytes and stripped encoding
header before request planning continues. Native image downloads still require
the source Referer and cookies. The standalone host test additionally checks
17-byte streaming reads, underlying-source closure and truncated-frame rejection.

## Download identity and row interaction

The active download screen shows its series and chapter with wrapping, followed
by n/m page progress. Session-owned copies preserve the same identification
when the job is destroyed after failure or cancellation. The persistent banner
retains progress and retry instructions. Stale success text is hidden while a
job is active; download preparation has its own page-list message.

Library titles, chapter rows, browse/search results, sources, extensions and
source-setting rows use fabrum's `ui.pressed(key)` and `ui.hovered(key)` queries,
matching drawn buttons' pressed shading. Main settings already use drawn buttons.
The exact same typed key is shared by interaction queries and row declaration.
No hand-maintained row pressed flag or sibling UI library changes are needed.

The InkView host uses dynamic partial interaction updates and disables automatic
full-screen cleaning for UI damage, so a row press/release cannot cross a global
counter and flash the screen. Reading explicitly requests full page refreshes
according to the preference, or every twelve reader updates in partial mode.
Tests verify both policies. In the 758×1024 fake panel, the pressed chapter's
update is partial at `(17,209)`, size `725×94` pixels; release clears the shading
with another small partial update. Tests inspect update kinds, row containment,
region sizes and framebuffer pixels across more taps than the old interval.

Actual framebuffer previews (generated by `zig build preview`, then losslessly
wrapped as PNG by `python3 tools/preview_png.py`):

- [Downloading](../preview/downloading.png).
- [Pressed chapter](../preview/pressed-chapter.png).
- [Canceled download](../preview/download-canceled.png).

The Debug cancellation test also exposed an existing error-propagation race:
HTTP body framing can return ReadFailed without setting bodyErr. The downloader
now reads the connection's underlying error in that case, preserving
`error.Canceled` instead of replacing it with NetworkReadFailed.

## On the reader

Deploy the rebuilt bundle yourself. Browse MangaFox/MangaDex, refresh the chapter
list and start a chapter: metadata should no longer report missing Zstd classes
or JNI initialization failures. Once planning completes, watch for native page
bytes/head_ms/body_ms/disk_ms lines and the chapter total; these remain the way
to measure real device speed. Confirm the series/chapter identification while
downloading and after cancel/failure, row shading on touch-down and clearing on
release, and successful completion opening the reader. Physical panel behavior,
website-specific responses and Wi-Fi throughput still need your device run.
